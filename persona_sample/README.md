# 6변수 페르소나 표본

KGSS 2023년 응답자를 FINALWT 가중치로 복원추출(n=200, seed=42)해서 만든 표본입니다. `persona_id`로 4수준 대조군 전부(없음/한국성인/성별+연령/6변수)에서 재사용하십시오 — 같은 응답자 집합이어야 조건 간 대응비교(within-persona)가 성립합니다.

- `성별+연령` 조건: 이 표본의 SEX/AGE 열만 사용
- `6변수` 조건: `persona_당신_하십시오체` 등 열 사용
- `페르소나 없음(C0)`/`한국 성인` 조건: 이 표본과 무관, 별도 프롬프트

**주의**: 페르소나 변수 6개(SEX/AGE/EDUC/MARITAL/REGION/URBAN)는 스크립트 docstring에 적힌 근거로 재구성한 것이라 팀 확인이 필요합니다. 다르면 `--vars`로 다시 생성하십시오.
